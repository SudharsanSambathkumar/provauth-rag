# ProvAuth-RAG

Reference implementation and experiments for **Provenance-Aware Authorization of Derived Knowledge in Hybrid
Vector–Graph Retrieval-Augmented Generation** (S. SambathKumar, 2026).

Hybrid RAG systems combine vector retrieval with knowledge-graph reasoning. Access control on documents,
chunks or graph edges does not decide whether a user may receive a **conclusion derived** from several
pieces of evidence with different permissions. This repository implements the framework from the paper:

- **Provenance polynomials** (`provenance.py`): `+` for alternative derivations, `·` for jointly required evidence
  (Green et al., 2007), kept in the PosBool[X] form that the Boolean authorization needs.
- **Provenance-preserving bounded Horn inference** (`inference.py`): P(h) = Σ_rules Π_body P(b), depth-bounded.
- **Derived-claim authorization** (`engine.py`): Auth_u(c) = φ_u(P(c)) ∧ Q_u(c), where φ_u is true if at least
  one complete derivation uses only evidence the user may read, and Q_u is the claim-level disclosure policy.
- **Hybrid pipeline**: authorized vector seeds (LSA embeddings) → per-hop authorized graph expansion →
  claim authorization → release.
- **Baselines** B0–B4 and the ablation P−Q, the oracle, and counterfactual noninterference tests (`experiments/run.py`).
- **Demo app** (`app/app.py`, Streamlit) showing every authorization decision with its provenance.

Benchmarks: [ProvAuth-Retail and ProvAuth-ITSM](https://github.com/SudharsanSambathkumar/provauth-benchmarks)
(copies in `datasets/`).

## Quickstart

```bash
pip install -e ".[app,figures,dev]"
pytest -q                              # unit tests
python experiments/run.py              # all experiments -> results/summary.json
python experiments/figures.py          # figures -> figures/
streamlit run app/app.py               # demo app
```

The experiments need no API key and no network access; every number in the paper is regenerated by
`experiments/run.py` on a CPU.

## Methods compared

| Id | Method | Graph expansion | Release rule |
|---|---|---|---|
| B0 | No access control | all evidence | release every derived claim |
| B1 | Seed-only ACL (vector seeds filtered) | all evidence | release every derived claim |
| B2 | Resource-level ACL (per-hop) | authorized evidence | release claims derived from authorized evidence |
| B3 | Single-witness provenance | authorized evidence | shortest derivation authorized ∧ Q |
| B4 | Lineage-based denial | authorized evidence | every contributing source authorized ∧ Q |
| P−Q | Proposed without claim policy | authorized evidence | φ_u(P(c)) |
| P | Proposed | authorized evidence | φ_u(P(c)) ∧ Q_u(c) |
